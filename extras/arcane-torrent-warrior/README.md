# Arcane torrent for High Elf Warrior

Add Arcane Torrent racial to High Elf Warrior based on Cataclysm version for Blood Elf Warrior: https://www.wowhead.com/cata/spell=69179/arcane-torrent

## Installation

After installing the base mod, just replace the files in server and client.

Restart the world server, and delete the Cache folder in the client.
